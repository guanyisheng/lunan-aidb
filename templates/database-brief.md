# 数据库业务说明模板（给外部 AI 填写）

把本文件连同库结构（或网站功能说明）发给任意 AI，让它按下面章节填空。
填完后整份 Markdown 粘贴进 Lunan AIDB → **记忆中心 → 数据库说明**，与项目绑定。
Agent 会优先用这份说明，把「查 id=1 的订单」「改 id=8 的余额」映射到真实表和字段。

## 4. 常用查询意图 → SQL 思路（多跳路径很重要）

写清「先找谁、再查什么」，不要只写最终表：

- 「查 shasha / 某昵称的余额」→ ① `users`（或…）按 `name/nickname` 找 `id` → ② `…余额表` 按 `user_id` 查余额字段 …
- 「查 id={N} 的订单情况」→ 查 `orders` where `id=N`，必要时 join 用户/明细表 …
- 「查 id={N} 的余额」→ 查 `…` 表的 `…` 字段 …
- 「最近 7 天订单统计」→ …
- 「修改某某状态」→ 先 SELECT 确认，再 UPDATE（写操作需人工审批）
